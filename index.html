What you get

The useful parts of crawling, without the ceremony.

Start with the API. Keep the deployment small. Add shared capacity only when the work actually calls for it.

Simple API surface

Scrape pages, crawl sites, and dispatch jobs through predictable HTTP endpoints built for automation.

Node-powered capacity

Run your own node locally or on a server, then contribute capacity to the network when you choose.

Made to stay light

Use the crawler as a focused service instead of carrying a heavyweight platform for every request.

Connect a node
